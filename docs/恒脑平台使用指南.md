## 1. 安全能力资产体系与复用规范

恒脑平台将安全能力划分为六大资产维度，在构建复杂安全智能体时可直接组装与复用：

| 资产类型 | 技术形态与载体 | 工程复用与集成方式 | 安全场景应用示例 |
| :--- | :--- | :--- | :--- |
| **安全智能体** (Agent) | 独立封装的已发布应用 | 通过工作流中的【智能体节点】作为子 Agent 嵌套调用。 | 接入现成的“恶意邮件研判智能体”、“钓鱼网站检测智能体”。 |
| **Agent Skills** (技能) | 预置/自定义通用安全逻辑模块 | 挂载至自规划节点或代码节点，跨多个智能体共享基础逻辑。 | “Nginx日志提取攻击IP”、“CVE编号漏洞信息补全”、“Base64/密文自动解码”。 |
| **API 工具** (RESTful Tools) | 基于 HTTP/RESTful 协议的接口包装 | 封装企业自建或外部系统 API，挂载至模型节点（自主决策）或插件节点（显式确定性执行）。 | ClickHouse 检索接口、SMTP 邮件代理、威胁情报 IOC 查询、EDR 隔离接口。 |
| **MCP 工具** (Protocol Tools) | 基于 Model Context Protocol 标准协议 | 接入 AI 原生开源工具生态，挂载至自规划节点与模型节点。 | `sqlmap-mcp`、`nuclei-mcp`、`ffuf-mcp` 等自动化扫描与测试协议。 |
| **安全知识库** (RAG Knowledge) | 向量化语义数据库 | 挂载至模型节点，根据上下文语义相似度自动召回。 | ATT&CK 战术技术矩阵、CVE 特征库、安全运营处置规范、等保合规基线。 |
| **基座模型** (Models) | 垂域/通用大语言模型 | 工作流节点底层引擎，支持按场景切换。 | 深度思考模型（强逻辑推理）、长窗口模型（长日志上下文分析）。 |

## 3. 开放服务（Open API）集成协议契约

平台提供标准化的 RESTful API，用于外部应用（如后端调度器、SOAR、SIEM、自动化脚本）调用已发布的恒脑智能体。

### 3.1 鉴权认证机制（Signature Authentication）
所有开放接口请求必须在 HTTP Header 中包含鉴权标识与动态签名：

- **Header 字段**：
  - `appKey`：在平台申请的应用唯一标识。
  - `sign`：动态计算的认证签名。
  - `Content-Type`：`application/json`

- **签名生成算法（HMAC-SHA256）**：
  $$\text{sign} = \text{timestamp} + \text{Base64}\Big(\text{HMAC-SHA256}\big(\text{timestamp},\; \text{appSecret}\big)\Big)$$
  - `timestamp`：当前 13 位毫秒级时间戳（例如 `1709703938860`）。
  - `appSecret`：应用密钥凭证。

- **Python 签名实现参考**：
  ```python
  import time, hmac, hashlib, base64

  def generate_auth_headers(app_key: str, app_secret: str) -> dict:
      timestamp = str(int(time.time() * 1000))
      mac = hmac.new(
          app_secret.encode('utf-8'),
          timestamp.encode('utf-8'),
          digestmod=hashlib.sha256
      ).digest()
      sign = timestamp + base64.b64encode(mac).decode('utf-8')
      return {
          "appKey": app_key,
          "sign": sign,
          "Content-Type": "application/json"
      }
  ```

### 3.2 核心接口定义

#### ① 同步执行智能体（Agent Execute）
- **请求方式**：`POST /open/api/v2/agent/execute`
- **请求 Body 参数**：
  ```json
  {
    "agent_id": "string",          // 必填，已发布的智能体ID
    "input": {                     // 选填，对应智能体【开始节点】定义的输入参数Schema
      "input": "研判日志原文...",
      "log_source": "suricata",
      "alert_id": "AL-2026-001"
    }
  }
  ```
- **响应 Body 结构**：
  ```json
  {
    "code": 200,
    "msg": "success",
    "data": {
      "session_id": "sess-xxxx",   // 会话ID，用于链路追踪
      "reply": "研判结论Markdown...", // 对应智能体【结束节点】的回答内容
      "results": {                 // 对应智能体【结束节点】配置的结构化输出对象
        "is_malicious": true,
        "attack_type": "SQLi",
        "attacker_ip": "198.51.100.1",
        "confidence": 0.95
      },
      "token_usage": {
        "prompt_tokens": 1200,
        "completion_tokens": 350,
        "total_tokens": 1550
      }
    }
  }
  ```

#### ② 中断恢复执行（Resume Interactive Node）
- **使用场景**：当智能体工作流执行到【交互节点】（如需要人工确认封禁 IP）时挂起，外部系统人工审批完毕后注回决策。
- **请求方式**：`POST /open/api/v2/agent/execute/resume`
- **请求 Body 参数**：
  ```json
  {
    "session_id": "sess-xxxx",     // 必填，挂起时的会话ID
    "action": "confirm",           // 审批动作标识
    "answers": {                   // 交互节点定义的问题回答
      "confirm_block": "yes"
    }
  }
  ```

#### ③ 异步任务提交与轮询（Async Task Workflow）
- **提交任务**：`POST /open/api/v2/agent/task/submit`（返回 `task_id`，适用于耗时超过 30s 的复杂全链路分析）。
- **查询状态**：`GET /open/api/v2/agent/task/status?task_id=xxxx`（返回 `PENDING` / `RUNNING` / `SUCCESS` / `FAILED`）。
- **获取结果**：`GET /open/api/v2/agent/task/messages?task_id=xxxx`。

#### ④ 文件传输接口
- **文件上传**：`POST /open/api/v2/agent/file/upload`（上传 pcap 解析日志、PCAP 文件等，返回平台文件引用标识）。
- **文件下载**：`GET /open/api/v2/agent/file/download?file_id=xxxx`（下载智能体处置生成的报告或证据包）。

## 4. 全链路排查与运行审计规范

### 4.1 关键追踪标头与日志串联
- **`会话ID` (session_id)**：穿透智能体单次执行全生命周期。包含开始节点输入、外部 API 插件请求与返回、模型 reasoning 过程、结束节点输出。
- **调用审计字段**：
  - `接口ID`：识别被触发的具体动作。
  - `智能体ID` (agent_id)：定位执行的智能体版本。
  - `x-real-ip`：记录调用方的真实发起 IP 地址。

### 4.2 常见调用故障排查 Checklist
1. **API 工具调用 404/500/网络超时**：
   - 原因：平台为公网 SaaS 环境，若外部接口部署在本地并未配置公网穿透，云端将连接超时。
   - 检查：在平台 API 工具页面重新点击“调试”，必须显示“成功”方可恢复。
2. **输出字段解析为 null**：
   - 检查【结束节点】的“输出参数”映射，验证使用的 JSONPath 语法是否与模型节点实际输出的 JSON 结构严格匹配。
3. **调用被拦截或报未授权**：
   - 检查系统时间戳偏差（本地时间必须 NTP 同步），验证 `appSecret` 参与 HMAC-SHA256 计算时的编码格式（UTF-8）。
