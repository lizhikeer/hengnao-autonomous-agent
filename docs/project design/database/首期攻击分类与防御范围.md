# 首期攻击分类与防御范围

| 攻击分类（`attack_type`） | 日志与关键字段 | 判定依据 | 处置范围 |
| --- | --- | --- | --- |
| 扫描探测 `Scan` | Web 访问日志（源 IP、路径、状态码）、Zeek 连接日志（目标、端口、连接结果） | 同源短时探测多个路径、端口或主机。按授权来源、目标及时段核验扫描权限。 | 自动限速、短时限制服务访问、关闭预授权的暴露入口。 |
| 密码爆破 `Brute_Force` | 认证日志（账号、源 IP、登录结果）、Web 或 SSH 操作记录 | 短时多次登录失败或同源批量尝试多个账号。后续登录成功时，结合常用来源、运维授权和账号操作确认是否失陷。 | 登录限速、短时拒绝该来源、撤销被盗会话。 |
| SQL 注入 `SQL_Injection` | Web 日志（请求参数摘要、响应状态、耗时、大小）、应用错误及操作日志、可用的数据库审计 | 可疑 SQL 片段与异常响应构成尝试线索。以关联请求或会话的审计及操作记录确认未授权登录、数据读取或导出。 | 拒绝恶意请求、暂停受影响接口中预授权的操作。 |
| 跨站脚本 `XSS` | Web 日志（提交内容摘要、页面访问）、认证及应用日志（会话 ID、源 IP、敏感操作）、可用的浏览器记录 | 可疑脚本提交构成尝试线索。浏览器记录用于确认脚本执行。页面访问后，同一会话被异常来源复用并执行敏感操作时，结合会话基线核实盗用。 | 拒绝恶意提交、隐藏恶意内容、撤销被盗会话。 |
| 目录遍历与越权 `Path_Traversal_Privilege` | Web 日志（路径、资源 ID、响应）、认证及应用日志（账号、角色、资源归属、操作结果） | 可疑路径或资源 ID 遍历构成尝试线索。根据响应内容及操作记录，确认是否读取目录外文件，或读取、修改权限范围外的资源。 | 拒绝违规访问、撤销涉事会话、暂停预授权的操作。 |
| 恶意上传 `Malicious_Upload` | Web 日志（文件元数据、上传响应、后续访问）、应用文件操作记录、Zeek 连接日志 | 文件类型异常构成尝试线索。文件保存或访问记录用于确认落地，执行审计或可归因的后续活动用于确认执行。 | 拒绝上传、隔离可疑文件、禁止访问已发布的恶意文件、隔离预授权主机。 |
| 可疑外连与数据外传 `C2_Exfiltration` | Zeek 日志（连接方向、目的地址、间隔、字节数）、可用的 HTTP、DNS 记录及同资产的 Web、认证日志 | 偏离业务基线的周期外连或流量突增构成线索。关联异常指令通信或资产失陷证据核实命令与控制（C2）。依据上传记录或审计确认向未授权目的地传输数据。 | 阻断恶意出口连接、隔离预授权主机。 |

Web 分类参照 WSTG v4.2 的信息收集（4.1）、身份认证（4.4）、授权控制（4.5）、输入校验（4.7）和文件上传（4.10.8–4.10.9）。[OWASP WSTG v4.2](https://wstg.owasp.org/v4.2/4-Web_Application_Security_Testing/)
