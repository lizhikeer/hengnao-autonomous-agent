# 首期攻击处置表

| 攻击分类 | 自动阻断 | 自动遏制正在发生的入侵 |
| --- | --- | --- |
| 扫描探测 | 未授权扫描达到阈值时限速。持续超限时，短时拒绝该来源访问被扫服务。授权扫描仅记录。 | 确认特定敏感资源已暴露时，停用预授权的下载入口。 |
| 密码爆破 | 登录失败达到阈值时限速。持续超限时，短时拒绝该来源访问对应的登录入口。 | 爆破后的成功登录与异常敏感操作关联时，撤销对应会话并要求重新认证。 |
| SQL 注入 | Web 应用防火墙（WAF）命中适用于该接口的阻断规则时，直接拒绝当前请求。 | 应用审计或数据库审计证实攻击经该接口绕过认证、读取或修改数据时，暂停该接口中预授权的敏感操作。 |
| 跨站脚本 | 命中阻断规则时，在保存或展示前拒绝恶意提交。 | 确认恶意内容已发布时，隐藏对应内容。确认会话被盗用时，撤销该会话。 |
| 目录遍历与越权 | 路径超出允许目录或账号无权访问目标资源时，直接拒绝当前请求。 | 审计证实同一会话正在越权读写时，撤销会话并暂停受影响接口中预授权的操作。 |
| 恶意上传 | 内容检查通过后才允许发布。确认恶意或违反上传规则时直接拒绝，待判定文件留在不可公开访问、不可执行的隔离区。 | 确认恶意文件已发布时，立即禁止访问该文件。确认已执行时，对符合预授权条件的单台主机实施网络隔离。 |
| 可疑外连与数据外传 | 命中已授权的出口阻断规则时，直接切断受影响资产到恶意目的地址的连接。周期外连或流量突增触发告警。 | 主机侧恶意进程或应用审计与出口日志相互印证，显示仍在回连或外传时，隔离符合预授权条件的涉事主机。 |

**执行权限。** 入口、应用和出口按规则实时拦截。Agent 可在处置端核验规则、证据和目标后触发表中的预授权动作，执行后立即通知值班人员。临时来源限制和接口限制到期解除。自动隔离限于已预授权且可替换的单台主机，保留运维和取证通道，由值班人员核验后解除。关键资产隔离、整 IP 封禁和账号停用仍走人工审批。 [Microsoft WAF 阻断与限速](https://learn.microsoft.com/en-us/azure/web-application-firewall/secure-web-application-firewall) · [Defender XDR 自动遏制](https://learn.microsoft.com/en-us/defender-xdr/automatic-attack-disruption) · [主机隔离范围](https://learn.microsoft.com/en-us/defender-endpoint/isolation-exclusions) · [OWASP 文件上传防护](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) · [OWASP 授权校验](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)
